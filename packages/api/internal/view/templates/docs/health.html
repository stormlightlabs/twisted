Health Endpoints

Twister exposes two health check endpoints for monitoring and orchestration.

GET /healthz

Liveness probe. Returns 200 if the process is responsive. No dependency checks.

Example Request

curl https://your-domain/healthz

Response

{"status": "ok"}

Always returns 200 OK.

GET /readyz

Readiness probe. Checks that the database is reachable by executing a test query.

Example Request

curl https://your-domain/readyz

Response (healthy)

{"status": "ready"}

Returns 200 OK when the database is reachable.

Response (unhealthy)

{"error": "db_unreachable", "message": "database is not reachable"}

Returns 503 Service Unavailable when the database cannot be reached.

Usage

Configure your orchestrator (Railway, Kubernetes, etc.) to poll these endpoints:

EndpointPurposeFailure Action
/healthzLivenessRestart the process
/readyzReadinessRemove from load balancer
