GET /search

Search indexed Tangled documents with keyword matching. Returns a paginated list of results with highlighted snippets.

Parameters

NameTypeDefaultDescription
qstringrequiredSearch query. Supports boolean operators, phrases, and prefix matching.
modestringkeywordSearch mode: keyword, semantic, or hybrid.
limitint20Results per page (1–100).
offsetint0Pagination offset.
collectionstring—Filter by ATProto collection NSID.
typestring—Filter by record type: repo, issue, pull, profile, string.
authorstring—Filter by author handle or DID.
repostring—Filter by repo name.
languagestring—Filter by programming language.
statestring—Filter by state: open, closed, merged.
fromstring—Created after (ISO 8601).
tostring—Created before (ISO 8601).

Example Request

curl "https://your-domain/search?q=rust+tui&type=repo&limit=5"

Query Syntax

The keyword search uses Tantivy query syntax:

FeatureExample
Boolean ANDgo AND search
Boolean NOTrust NOT unsafe
Phrase"pull request"
Prefixtang*
Field-scopedtitle:parser

Errors

StatusCondition
400Missing q, invalid limit/offset, unknown parameters.
500Internal search failure.
